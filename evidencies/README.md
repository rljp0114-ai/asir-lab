# Evidencias

Esta carpeta guarda el registro general de comandos del laboratorio: [`Comandos.md`](Comandos.md).

Las capturas están en la carpeta `evidencies/` de cada tarea, junto a los documentos que las citan:

- [`04-diseno-red/evidencies/`](../04-diseno-red/evidencies/)
- [`05-instalacion-comunicaciones/evidencies/`](../05-instalacion-comunicaciones/evidencies/)

## Convención de nombres

`fecha-sistema-prueba.png`, por ejemplo `2026-11-16-mikrotik-webfig-resources-version.png`.

## Buenas prácticas

- Explicar cada evidencia en el documento correspondiente.
- No guardar contraseñas, claves privadas, tokens ni información personal innecesaria.
- No subir discos virtuales ni imágenes ISO.
