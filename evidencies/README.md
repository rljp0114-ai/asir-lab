# Evidencias

Guardar aquí capturas y salidas de comandos que acrediten las configuraciones y pruebas.

## Convención de nombres
Usar nombres descriptivos, por ejemplo:
- `2026-10-27-virtualbox-debian-adaptadores.png`
- `2026-10-27-debian-ip-br-address.txt`
- `2026-10-27-debian-ip-route.txt`

Sustituir la fecha por la fecha real.

## Buenas prácticas
- Explicar cada evidencia en el documento correspondiente.
- No guardar contraseñas, claves privadas, tokens ni información personal innecesaria.
- No subir discos virtuales ni imágenes ISO.
